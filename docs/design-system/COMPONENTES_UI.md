# COMPONENTES UI

## Navegacion
- Header principal del cuaderno.
- Breadcrumb de curso > trimestre > sesion.
- Paginacion de sesion anterior/siguiente.

## Estructura de sesion
- Hero de sesion con objetivo didactico.
- Bloque "Explicacion".
- Bloque "Practica".
- Checklist de materiales.
- Recursos y enlaces ampliados.

## Soporte al aprendizaje
- Tarjetas de concepto clave.
- Alertas didacticas: consejo, error comun, reto.
- Bloque de preguntas de autoevaluacion.

## Accesibilidad
- Barra de accesibilidad fija (lectura, audio, modos daltonismo).
- Boton "saltar al contenido".
- Selector de tamano de texto.
- Modo alto contraste.

## Estados
- Default, hover, focus, active, disabled.
- Estado completado para actividades.
- Estado pendiente para contenido aun no trabajado.
