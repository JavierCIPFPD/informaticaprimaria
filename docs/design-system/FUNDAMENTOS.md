# FUNDAMENTOS - Design System

## Proposito
Definir la base visual y de experiencia para el cuaderno de Informatica para primaria.

## Principios
- Claridad antes que decoracion.
- Legibilidad alta para alumnado de 11-12 anos.
- Tono formal y cercano.
- Accesibilidad por defecto (WCAG 2.1 AA).
- Responsive mobile-first.

## Direccion visual
- Estetica: cuaderno tecnico con detalles ludicos moderados.
- Jerarquia: titulos muy claros, bloques cortos y apoyos visuales.
- Interaccion: feedback inmediato y sencillo.

## Tipografia
- Texto principal: fuente sans-serif de alta legibilidad.
- Titulares: variante con personalidad moderada y buen contraste.
- Escala fluida y consistente por breakpoint.

## Color
- Paleta principal con contraste AA minimo.
- Color nunca como unico indicador de estado.
- Estados semanticos definidos: exito, aviso, error, info.

## Movimiento
- Animaciones cortas y funcionales.
- Respetar prefers-reduced-motion.

## Accesibilidad
- Navegacion completa por teclado.
- Foco visible y consistente.
- Etiquetas y nombres accesibles en controles.
- Texto alternativo significativo en imagenes.
- Barra de accesibilidad visible y operable.
